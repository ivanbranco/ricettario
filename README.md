# Il mio ricettario

Sito personale di ricette vegetariane.

Ogni ricetta è una pagina HTML a sé, che funziona anche offline: le dosi si adattano alle porzioni, si possono cambiare le unità di misura e c'è una lista della spesa da copiare o mandare su Telegram. Dall'indice (`index.html`) si cerca per nome, ingrediente o difficoltà.

Le regole per scrivere una nuova ricetta sono in [FORMATO.md](FORMATO.md).
